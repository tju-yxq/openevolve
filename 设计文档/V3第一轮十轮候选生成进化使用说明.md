# V3 十周期 8→4→2 候选进化使用说明

> 当前分支：`codex/v3-mapping`
>
> 协议版本：`v3-qm9-alpha-8-4-2@1`
>
> 每周期候选数：8
>
> 多保真晋级：8k 全部 8 个 → 80k Top 4 → 250k Top 2
>
> batch size：8
>
> 周期数：10

## 一、先纠正“每轮”的定义

正式进化中的一轮是一个完整的**进化周期**，不是生成一个子代：

```text
当前最优父架构 P_t
    ↓ 冻结父代，不在候选生成期间更新
生成 8 个架构 ID 唯一的直接子代
    ↓ 固定训练集 1/4，batch size=8
8 个候选训练至 8,000 steps
    ↓ 只按冻结的 Validation 指标
Top 4 在同一固定 1/4 数据上续训至 80,000 steps
    ↓ 只按同一 Validation 指标
Top 2 切换完整训练集，训练至 250,000 steps
    ↓
250k Validation 赢家成为下一周期父架构 P_{t+1}
```

候选内部仍可使用：

```text
Factor Router → Region Critic → Patch Synthesizer → 条件 Compiler Repair
```

但这是**单个候选的 LLM 局部补丁生成协议**，不能代替 8k→80k→250k 的多保真训练阶段。

## 二、冻结的实验协议

当前第一版固定为 QM9 极化率任务，用于和原 V1 实验保持同一数据与目标：

- 数据集：QM9；
- 目标：`alpha`，target index 1；
- batch size：8；
- 随机种子：201；
- 8k、80k：同一个 seed=201 的固定训练集 1/4；
- 250k：完整训练集；
- 晋级指标：终点 `validation_alpha_mae`，越低越好；
- Test：搜索和晋级期间禁止访问；
- 等变合同：平移不变、SO(3) 旋转下标量不变、原子置换不变；当前类型合同不把镜像反射写成已证明性质；
- 8k→80k：恢复模型、Optimizer、Scheduler 与 RNG；
- 80k→250k：保留模型与 global step，切换完整数据并重建 Optimizer/LR 阶段。

协议文件：

- `configs/dsl_v3_qm9_alpha_dataset_manifest.json`
- `configs/dsl_v3_qm9_alpha_equivariance_contract.json`
- `configs/dsl_v3_qm9_alpha_8_4_2_protocol.json`
- `configs/dsl_v3_qm9_alpha_seed.json`

运行开始后，数据 manifest、1/4 子集、等变合同和整个训练协议均计算 SHA-256；续跑时任一身份变化都会被拒绝。

## 三、第一周期生成 8 个固定父代兄弟候选

```powershell
python scripts/run_dsl_v3_cohort.py `
  --model-config configs/dsl_v3_qm9_alpha_seed.json `
  --protocol-config configs/dsl_v3_qm9_alpha_8_4_2_protocol.json `
  --output output/v3_cycles/cycle_001/cohort `
  --cycle-index 1 `
  --cohort-size 8 `
  --selection-mode glm `
  --model glm-5.2 `
  --validation-level static `
  --equiformer-v3-root C:\path\to\equiformer_v3_official
```

该脚本强制：

1. 8 个候选都以同一个父 DSL 为输入；
2. 父架构在该批次生成期间不更新；
3. 8 个候选的架构 ID 和随机路径状态全部唯一；
4. 每个候选均保存 Router、Critic、Synthesizer、Patch、规范化 DSL 与 Lowering manifest；
5. 候选仅生成和检查，不提前决定下一周期父代。

确定性 smoke 已验证：生产宽度 Energy-only V3 基线包含 529 个 DSL 节点；8/8 候选唯一，且全部是同一父架构 `178046bd3d4973da` 的直接子代。

## 四、对一个候选批次执行 8→4→2 多保真训练

```powershell
python scripts/run_dsl_v3_multifidelity.py `
  --root output/v3_cycles/cycle_001/multifidelity `
  --cohort-dir output/v3_cycles/cycle_001/cohort `
  --protocol-config configs/dsl_v3_qm9_alpha_8_4_2_protocol.json `
  --equiformer-root C:\path\to\equiformer `
  --equiformer-v3-root C:\path\to\equiformer_v3_official `
  --data-path C:\path\to\qm9 `
  --quarter-subset-file data_splits/qm9_train_quarter_seed201.npz `
  --python C:\path\to\training-python.exe
```

控制器会顺序完成：

- `quarter_8k`：8 个候选从头训练至 8k；
- `quarter_80k`：按 8k 终点 Validation MAE 取 Top 4，精确续训至 80k；
- `full_250k`：按 80k 终点 Validation MAE 取 Top 2，切换完整训练集并训练至 250k；
- 写出 `next_cycle_parent.json`：250k Validation 赢家的 DSL、架构 ID 与 Checkpoint。

训练模型由 `equivariant_nas/training/v3_qm9_runtime.py` 将 PyG/QM9 batch 映射为 V3 Typed DSL 输入，再通过通用 e3nn Graph Lowering 构建；运行时显式拒绝官方 `EquiformerV3_OC`、`TransBlockV3`、`EquivariantGraphAttention` 和 `ScalarFeedForwardNetwork` 构造器旁路。

## 五、连续执行 10 个进化周期

```powershell
python scripts/run_dsl_v3_cycles.py `
  --root output/v3_10_cycles `
  --model-config configs/dsl_v3_qm9_alpha_seed.json `
  --protocol-config configs/dsl_v3_qm9_alpha_8_4_2_protocol.json `
  --equiformer-root C:\path\to\equiformer `
  --equiformer-v3-root C:\path\to\equiformer_v3_official `
  --data-path C:\path\to\qm9 `
  --quarter-subset-file data_splits/qm9_train_quarter_seed201.npz `
  --training-python C:\path\to\training-python.exe `
  --selection-mode glm `
  --model glm-5.2
```

第 1 周期从固定 V3 seed 开始；第 2～10 周期只读取上一周期的 `next_cycle_parent.json`。未完成 250k 或未产生冻结 Validation 赢家时，控制器禁止进入下一周期。
