# 作废说明

本目录对应错误的“单候选连续谱系”解释，已于 2026-08-01 主动停止，不得作为正式 V3 进化证据。

错误流程是：每次从上一候选继续生成一个子代，并把候选内部的 `Factor Router → Region Critic → Patch Synthesizer` 误当成整个进化轮次的三阶段。

正式协议应为：

1. 每个进化周期冻结当前最优父架构；
2. 从同一个父架构生成 8 个架构 ID 唯一的直接子代；
3. 8 个候选在固定训练集 1/4、batch size 8 下训练到 8,000 steps；
4. 按冻结的 Validation 指标选择 Top 4，在同一固定 1/4 数据上续训到 80,000 steps；
5. 再选择 Top 2，切换完整训练集并训练到 250,000 steps；
6. 250,000-step Validation 赢家才成为下一进化周期的父架构；
7. 数据集身份、1/4 子集哈希、等变规则、任务合同、训练协议和 Test 隔离在整个运行中不可改变。

本目录中已完成或未完成的候选仅用于定位错误实现，不参与正式排序、晋级或下一父代选择。
